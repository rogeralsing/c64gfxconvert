## Original Amiga MOD channels

Each WAV covers 0:00–5:33.84, with the same decoder settings and gain. Silence
stays at its original time; no channel is normalized separately. These are
independent libopenmpt renders, not physical Amiga recordings or SID imitations.

- [Channel 1](amiga-channel-1.wav)
- [Channel 2](amiga-channel-2.wav)
- [Channel 3](amiga-channel-3.wav)
- [Channel 4](amiga-channel-4.wav)

The reported bright sound around six seconds still needs isolated listening.
Channel 2's lead retriggers at 5.76 seconds. Channel 3 plays a snare at 6.00
seconds and an orchestral hit at 6.72 seconds. The current C64 phrase omits
channel 3 and changes channel 2's timbre. Neither attribution is settled by
note data alone.

[channel-map.json](channel-map.json) records instrument use and note events.
[original-channels.json](original-channels.json) records source identities,
isolation checks and reconstruction measurements.

Reproduce the four original channels from the repository root:

```sh
rtk proxy experiments/mod-hybrid/.venv/bin/python experiments/sid-voice-sampler/work/hyperbased/render_original_channels.py
```

The reconstruction check sums the four independent renders for verification
only. No mixed listening file is generated by that check.

## Current native mix

[Listen to the VICE recording](linus-mix/hybrid.wav),
[run the PRG](linus-mix/player.prg), or read [compact measurements](mix-check.json).

The supported mixer follows [Linus Akesson's Platform Hopping](https://linusakesson.net/music/platform-hopping/index.php).
The C64 mixes original channel 1's software triangle bass with channel 4's
sampled drums through SID voice 3. Channel 2 keeps its pulse approximation on
SID voice 1. SID voice 2 is available and rests in this musical proof. Channel
3 remains unselected; the orchestral hit has not been restored.

This proof covers only 0:00–0:20. It is not a full-song or four-channel MOD
conversion. The separate runtime capacity test plays both ordinary SID voices
while bass and drums share the third voice, proving four logical parts can run.

The bass uses a 16-bit phase and sixteen-level triangle with the original gain
changes. Drum instruments are filtered at their declared fixed playback pitches
and reused as frame pages. The C64 adds the two independent values for every
sample. Linear headroom prevents wraparound; this is not a general mixer for
two freely pitched samples.

Actual VICE verification covers 156,389 mixed values, 6,000 SID writes and exact
126-cycle intervals, with zero underruns. Both inputs contribute simultaneously
to 58,397 output values. Minimum foreground deadline margin is 110 cycles per
buffer. The display is off; screen-on and physical SID operation remain unverified.
The WAV uses no host mixing, EQ or alignment. Listening acceptance remains open.

Build, record and measure the same phrase from the repository root:

```sh
rtk proxy experiments/mod-hybrid/.venv/bin/python experiments/sid-voice-sampler/build_linus_mix.py
```

Generated pages, score, full traces and measurements stay under `linus-mix/`.
The [project instructions](../../AGENTS.md) define this as the only supported
build path. Choose subsequent musical parts from the separate original channels;
the phrase detector has not yet been implemented.
