# Accepted sampled C3 reference

[source-c3-sampled.wav](sampled-c3/source-c3-sampled.wav) is the accepted isolated
3.84-second recovery, using the original channel3 instruments at 7.82 kHz.
Its matching PRG and digital proof remain beside it. Preserve their bytes.

This is a listening reference, not an alternate build path. The supported
builder now renders the complete twenty-second arrangement with original C3
samples on SID2 at 1.95 kHz. See the working-folder README and project AGENTS.md.
