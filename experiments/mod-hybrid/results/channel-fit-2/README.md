# Channel 2: sequence fitting and actual C64 auditions

Only original MOD track 2 is being fitted. The comparison is the complete
30–50s passage of *Stardust Memories*: 96 triggers across samples 14, 13, 15,
1 and 7. The other original tracks are muted. No result here establishes that
the instrument imitation is perceptually convincing.

## Listening results

`audition/` contains level-matched original/C64 pairs and a manifest. Each pair
plays the original for 20 seconds, pauses, then plays the same channel and
passage from actual VICE output. One pair uses the optimized SID bank; another
uses original sample waveforms through the C64's volume DAC as a control.
Pitch, timing and equalization are not changed by the audition packaging.

The SID audition is generated by `final-vice/sequence.prg`, a standalone
10,804-byte program. It runs the channel from 0–50s so the comparison is not
made from fresh chips for each note. The selected 30–50s phrase contains all
five fitted instruments. Unfitted instruments outside that phrase remain
silent; this is not a complete-song replacement for the earlier MOD player.

`final-vice/vice/capture.json` records 10,000 frames, no underruns, and actual
register state agreement at both 1ms and 2ms into every 200Hz frame. Its audio
is recorded by VICE, rather than assembled from host-side instrument stems.

The final fixed-rate comparison is in `audition/manifest.json`:

| Actual C64 rendition | Total objective | Spectral | Harmonic shape | Envelope |
| --- | ---: | ---: | ---: | ---: |
| Earlier v2 SID | 0.714961 | 0.81685 | 0.38419 | 0.41024 |
| Sequence-fitted SID | 0.604182 | 0.90692 | 0.41500 | 0.47175 |
| Original-waveform PCM control | 0.478761 | 0.58483 | 0.12265 | 0.08935 |

Lower is better for these errors. The fitted SID improves the total chiefly
through absolute frequency/register behavior; spectral shape and envelope
do not improve over v2. This tradeoff prevents calling the result a convincing
instrument match. The PCM control remains better under the fixed objective.
Audition files, not a percentage interpretation of the score, are the relevant
listening comparison.

## What was optimized

- Several real notes and pitches per instrument, concatenated with native
  SID state carried across retriggers.
- Waveform programs, pulse width/motion, ADSR, gate duration, pitch onset,
  filter mode, cutoff motion, resonance and filter tracking.
- Relative instrument levels and parameters over the entire 20-second phrase.
- Final validation with the full 0–50s prefix, not only a short warmup.

The objective in `../../sequence_loss.py` uses multi-resolution spectra,
absolute frequency distributions, harmonic shape, envelope and onset/offset
behavior. It allows one global recording gain, with no candidate-specific
pitch shift, time alignment, onset trimming or time warp. Known octave shifts,
time shifts, silence and nearly identical audio are independent controls in
`loss-diagnosis.json`. Its spectral-frequency distances are not certified
fundamental-note errors or recognition percentages.

The main search stages contain 8,486 candidate evaluations; separate bounded
tests examined two voices and arpeggios. A small improvement on isolated notes
did not survive the full phrase for arpeggios, so those candidates were
rejected. The final SID bank uses one oscillator and the shared SID filter.
Sharing that filter with other music channels is separate integration work.

## Existing SID instruments used as starting candidates

The official [GoatTracker distribution](https://cadaver.github.io/tools.html)
contains playable song sources with their actual instruments. Eight seeds
were decoded from five example songs, including Koto/Fast Koto from *Dojo*,
Harpsichord/Flute from *Transylvanian Whipping*, and Pulse Lead from
*The Consultant*. Additional Powerchord and major/minor arpeggio tables were
examined from *Unleash* and *The Consultant*.

`sid-examples.json` retains AD/SR, first waveform, gate timer and reachable
wave/pulse/filter/speed tables. The root renderer adapts those programs to the
original MOD note sequence; it is not the original GoatTracker song player.
The native screening and refinement explicitly included source-derived
programs, but the final selected parameter bank was not an unmodified source
instrument. No claim is made that an example already matches this recording.

The versioned primary archive, its checksum, author links and retained license
are documented in `sid-examples.md`. Existing song source files remain under
`../../sources/sid-examples/`.

## Matching the real export engine

An initial reSIDfp candidate scored better natively but did not improve when
exported to VICE. It is excluded from the final conclusion. VICE's actual
reSID core and filter defaults differ from that initial native renderer.

`../../channel_resid.cpp` and `../../channel_resid.py` build a narrow bridge
to the exact official VICE 3.10 reSID source matching the installed emulator.
The matched configuration is MOS6581, resampling, 90% passband, 97% gain and
500mV filter bias. `resid-core/` retains the source archive checksum, compiler
configuration, source/license, settings and calibration receipts.

Replaying VICE's actual register-bus timestamps through that bridge gives
0.999998 waveform correlation with VICE output. Source-frame writes and the
6502 decoder differ slightly within each frame; all final quality comparisons
therefore use the actual VICE capture, not merely the native search score.

## PCM control

`pcm-control/c64/stardust.prg` is a separate 8,455-byte control using the
original selected-channel waveforms, quantized to four bits at 3,848.625Hz.
All tonal SID voices are off. It uses the full single-channel volume-DAC
range, with no old per-voice halving. `pcm-control/receipt.json` documents
downsampling, quantization and actual playback verification. Its Nyquist
limit is 1,924.3125Hz. This control tests sequencing and waveform preservation;
it is not evidence of SID oscillator imitation.

## Reproduce the matched-engine stages

From the repository root, using the existing Python environment:

```sh
rtk proxy env MOD_CHANNEL_ENGINE=resid experiments/sid-inverse/.venv/bin/python experiments/mod-hybrid/fit_channel.py --out experiments/mod-hybrid/results/channel-fit-2/resid-search --refinements 640
rtk proxy env MOD_CHANNEL_ENGINE=resid experiments/sid-inverse/.venv/bin/python experiments/mod-hybrid/refine_phrase.py --input experiments/mod-hybrid/results/channel-fit-2/resid-search/result.json --out experiments/mod-hybrid/results/channel-fit-2/whole-refined --evaluations 160
rtk proxy experiments/sid-inverse/.venv/bin/python experiments/mod-hybrid/sequence_player.py --input experiments/mod-hybrid/results/channel-fit-2/whole-refined/frameevents-full.json --out experiments/mod-hybrid/results/channel-fit-2/final-vice --capture
```

Earlier search directories and failed native/export comparisons are preserved
as evidence. Later target passages are reserved for separate validation;
they contain additional instruments that this five-instrument bank does not
yet cover. They were not used to choose the final bank.
